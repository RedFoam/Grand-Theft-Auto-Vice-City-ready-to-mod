# GTA Vice City — Ready to Mod 🌴

## Everything You Need in One Place

This project was created to make modding **Grand Theft Auto: Vice City Classic (PC)** easier.

Instead of searching across multiple websites, tracking down individual patches, finding dependencies, and figuring out which files you need to get the game running properly on modern hardware, this repository brings the essential files and useful mods together in one convenient place.

The goal is simple: **download the pack, copy the files into your GTA Vice City game folder, and get ready to play.**

This setup targets the **retail v1.0 executable** and combines compatibility improvements, bug fixes, controller support, widescreen support, extended draw distance, and extra gameplay features.

## 🚀 Installation

Getting started is simple!

1. Download this repository.
2. Open your GTA Vice City installation folder — the folder containing `gta-vc.exe`.
3. **Copy all files and folders from this pack directly into your GTA Vice City game folder.**
4. Allow folders to merge if Windows asks.
5. Launch the game and enjoy!

Keep the included folder structure intact when copying files. If Windows asks to overwrite an existing file, make sure you're using the intended game version and files.

## ⚙️ Requirements

- A legitimate PC copy of Grand Theft Auto: Vice City Classic.
- The **retail v1.0 executable** This Includes The V1.exe File Needed.
- A Windows PC.

## ⚠️ Important Notes

- Back up your original game files before installing.
- This pack is designed for the retail v1.0 executable; other versions may not be compatible.
- The included mods have been tested together in the author's setup, but compatibility may vary on other systems.
- SkyGfx is not included.
- Some additional mods may require separate dependencies or installation instructions.
