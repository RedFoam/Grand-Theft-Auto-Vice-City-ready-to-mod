Destroyable Airtrain Mod 1.0
by Silent


DESCRIPTION

	This modification restores some beta GTA III code, allowing the player to blow up the Airtrain.
	In the final game version, the player could only destroy a Dodo flying above the city, yet destroyable
	Airtrain was shown in some places before III release (such as a German TV commercial).


INSTALLATION

	Easy as pie. Extract archive content to your III/VC directory or 'mss' directory and that's all.
	Changes will take effect automatically.


	Check modification's source code at GitHub!
	https://github.com/CookiePLMonster/Destroyable-Airtrain


SUPPORTED GAME VERSIONS

	* GTA III 1.0 (all versions)
	* GTA III 1.1 (all versions, including Steam version)
	* GTA VC 1.0 (all versions)
	* GTA VC 1.1 (all versions, including Steam version)
