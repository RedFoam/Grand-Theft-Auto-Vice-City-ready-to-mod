# GTA Vice City — Ready to Mod 🌴

A ready-to-play mod pack for **Grand Theft Auto: Vice City Classic (PC)**, using the retail **v1.0 executable**.

This pack brings together bug fixes, controller support, widescreen improvements, extended draw distance, and extra gameplay features. The goal is simple: copy the files into your game folder and enjoy Vice City with a collection of useful improvements.

## 🚀 Installation

Getting started is simple!

1. Download this repository.
2. Open your GTA Vice City installation folder — the folder containing `gta-vc.exe`.
3. **Copy all files and folders from this pack directly into your GTA Vice City game folder.**
4. Allow folders to merge if Windows asks.
5. Launch the game and enjoy!

**Important:** Keep the included folder structure intact when copying files. If Windows asks to overwrite an existing file, ensure you're using the intended game version and files.

## ⚙️ Requirements

- Grand Theft Auto: Vice City Classic for PC.
- The **retail v1.0 executable** This Includes The V1.exe File Needed.
- Windows PC.

## ⚠️ Important Notes

- Back up your original game files before installing.
- This pack is intended for the retail v1.0 executable; other versions may not be compatible.
- The mods have been tested together in the author's setup, but compatibility can vary on other systems.
- **SkyGfx is not included** in this pack.
- Additional mods may require separate dependencies or installation instructions.
- Do not replace loader DLLs with unrelated versions without checking compatibility.
